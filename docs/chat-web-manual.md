# Chat web sin API — intercambio manual

Esta modalidad abre [DeepSeek](https://chat.deepseek.com/) o [ChatGPT](https://chatgpt.com/) en tu navegador habitual. No necesita clave API. Cada sitio administra su cuenta, disponibilidad, límites y condiciones; no se promete uso gratuito ilimitado.

1. Escribí tu mensaje en el cuadro principal de Companion sin enviarlo.
2. Pulsá **Chat web sin API**. Revisá el mensaje preparado; podés editarlo.
3. Pulsá **Copiar mensaje revisado** y **Abrir chat en mi navegador**.
4. Iniciá sesión en el sitio si te lo pide, pegá el texto y enviá vos.
5. Copiá su respuesta, volvé a Companion y pegala en el cuadro inferior.
6. Pulsá **Incorporar respuesta al chat**. Aparece con aviso de origen manual y se lee si la voz está habilitada y preparada.

Se incluye únicamente el mensaje actual y una plantilla de personalidad amistosa con el nombre elegido. No se incluyen automáticamente memoria, historiales, títulos de ventanas ni personalidad avanzada. La preparación es una plantilla, no una llamada a Ollama. El texto editado del prompt no se guarda: el chat conserva el mensaje original y la respuesta pegada según el perfil activo.

Abrir el sitio no envía tu mensaje: la URL no contiene el prompt. Companion no inspecciona cookies, sesiones, páginas ni portapapeles; el pegado lo realiza el usuario. La app no comprueba de dónde proviene la respuesta. Puede ser inexacta y no ejecuta acciones por decir que lo hizo.

Modo privado bloquea esta modalidad y descarta su borrador interno. No cierra tu navegador ni borra lo copiado en el portapapeles del sistema. El proveedor puede conservar lo que le enviaste según su política. No hay sincronización automática con chats web ni controles de límites/cuotas del sitio.

Pruebas sintéticas cubren URLs sin prompt, importación explícita, límites y bloqueo privado; no equivalen a probar una sesión autenticada en cada sitio ni a aceptación auditiva.
