# Contribuciones

Por ahora el proyecto no acepta aportes externos, pull requests ni propuestas de cambios para integrar. El desarrollo se mantiene dentro del equipo del proyecto.

El código está disponible bajo Apache-2.0: podés estudiarlo, copiarlo, modificarlo y redistribuir tu propia versión cumpliendo sus condiciones. Esta política de recepción de contribuciones no agrega restricciones a la licencia.

Si en el futuro se abre la colaboración, este archivo indicará el proceso.
